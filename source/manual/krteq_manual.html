02 Connect to VIA

VIA allows you to easily change the keyboard layout or settings. Follow the steps below to complete the VIA interface setup.

  1. Get krteq_via.json from github.com/swift502/Krteq/production
  2. Visit usevia.app
  3. In the Settings tab, enable Show Design tab
  4. In the Design tab, click Load and select the JSON file
  5. Refresh the page (F5)
  6. In the Configure tab, click Authorize device and select Krteq

03 Customization

You can add more interactive screens or override the built-in behaviors by compiling your own QMK user keymap. Documentation and examples are available in the GitHub README.

And if you find more built-in behaviors that you think should be exposed for overrides, let's discuss it on GitHub and improve the firmware!

04 Disassembly

If the keyboard stops working, it might be possible to repair it by replacing a part or repairing some of the solder joints.

  1. Unplug the USB cable from the back
  2. Unscrew the 6 screws holding the plate
  3. Separate the case from the plate

Components

The OLED display and USB breakout board can be replaced after desoldering their connections.

  • The OLED display is only clipped in. To remove it, push down on it from the top side.
  • The USB breakout board is secured with two more screws. Unscrew them to replace the board.
