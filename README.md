# Krteq

## Parts

- 61x Gateron KS-33B (GLP 3.0) switches
- 61x MX Low-Profile Shinethrough Keycaps
- Gateron 2u Low-Profile Plate Mounted Stabilizer
- Raspberry Pi Pico
- 15cm (6") USB Panel Mount Extension Cable
- Rubber feet
