02 CONNECT TO VIA

VIA allows you to easily change the keyboard layout or settings. However a custom design file must be uploaded to make it work.

  1. Get krteq_via.json from github.com/swift502/Krteq/production
  2. Visit usevia.app
  3. In the Settings tab, enable Show Design tab
  4. In the Design tab, click Load and select the JSON file
  5. In the Configure tab, click Authorize device and select Krteq
